# 3D Texture Simulator

브라우저에서 바로 실행되는 3D 텍스쳐 시뮬레이터입니다.  
Three.js 기반으로 원단/소재 텍스쳐를 실시간으로 3D 렌더링합니다.

## 실행 방법

`3D Texture simulator v10.html` 파일을 브라우저에서 열기만 하면 됩니다.

## 파일 구조

| 경로 | 설명 |
|------|------|
| `3D Texture simulator v10.html` | 최신 버전 (메인) |
| `image/` | 텍스쳐 이미지 에셋 |
| `versions/` | 이전 버전 기록 (v1 ~ v9) |

## 버전 히스토리

| 파일 | 비고 |
|------|------|
| `Premium texture.html` | 초기 버전 |
| `Premium texture v2.html` ~ `v7.html` | 기능 추가 단계 |
| `3D Texture simulator v8.html` | 3D Simulator로 개편 |
| `3D Texture simulator v9.html` | v9 |
| `3D Texture simulator v10.html` | **최종 버전** |

## 기술 스택

- Vanilla HTML + CSS + JavaScript
- Three.js (3D 렌더링)
